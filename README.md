# Simon Says Game

A fast-paced browser memory game inspired by the classic Simon memory challenge. Players must watch the flashing pattern, repeat it correctly, and survive as many levels as possible.

## Demo

Live demo: https://simon-says-beta-lyart.vercel.app/

## Features

- Classic Simon-style gameplay with color sequence memory
- Multiple difficulty modes: Easy, Medium, and Hard
- Countdown timer for each round
- Pause and resume support
- Sound toggle with interactive audio feedback
- High score tracking using local storage
- Responsive UI with a polished neon theme

## How to Play

1. Click the Start button or press any key to begin.
2. Watch the flashing color pattern carefully.
3. Repeat the sequence by clicking the matching buttons.
4. Each correct round increases the level and adds a new color to the pattern.
5. If you click the wrong sequence or run out of time, the game ends.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS

## Run Locally

1. Open the project folder in your browser or use a local server.
2. Start a simple local server from the project directory, for example:

```bash
python -m http.server 8000
```

3. Open http://localhost:8000 in your browser.
